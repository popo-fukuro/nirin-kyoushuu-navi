# 二輪教習ナビ

普通自動車免許を持っていて、これから普通二輪（MT）の教習を受ける人のための予習アプリです。教習でやる8項目をタップすると、「やること・コツ1行・予習動画1本」がすぐにわかります。

👉 **今すぐ使う：https://popo-fukuro.github.io/nirin-kyoushuu-navi/**

## こんな人に
- 「次の教習で何をやるの？」を、前の晩にサッと確かめておきたい人
- 予習動画が多すぎて、どれを見ればいいか選べない人
- AT限定の普通免許で、クラッチやギアチェンジが初めての人

## 使い方
1. ページを開いて、気になる項目（一本橋・スラローム・急制動など）をタップする
2. 「やること」と「コツ」を読んで、「▶ 予習動画を見る」で動画を1本だけ見る
3. 見終わったら「予習したらチェック」を押す。上のバーで、8項目のうちいくつ予習したかがわかります

登録もインストールもいりません。スマホのブラウザで開けば、そのまま使えます。

## 載っている8項目
引き起こし・取り回し／発進・停止／変速（ギアチェンジ）／坂道発進／S字・クランク／一本橋／スラローム／急制動

各項目の説明とコツは、2つ以上の情報源（公開されている試験の基準や、教習の解説記事など）と照らし合わせて書いています。出典と確認した日は、ページの下の「出典と確認日」で見られます。

## 予習動画について
予習動画は、YouTube にある**ほかの人が作った動画へのリンク**です（このアプリの中で再生したり、保存したりはしていません）。
その項目のやり方を解説している動画のうち、調べた範囲で再生回数がいちばん多かったものを選びました（2026-10-04 時点）。
動画の内容や公開状況は、それぞれの制作者によります。動画が見られなくなることもあります。

## データについて
「予習した」のチェックは、あなたの端末（ブラウザ）の中だけに保存されます。どこにも送信されません。
（ブラウザのデータを消すと、チェックも消えます。ほかのスマホやブラウザには引き継がれません）
